🏦 IBKR Flex Query Import

Setup (one-time)

  1. Log into IBKR Client Portal → Performance & Reports → Flex Queries
  2. Create an Activity Flex Query including the Trades section
  3. Under Delivery Configuration → Date Range, choose a period that covers both your entry and exit dates. A safe default is Last 30 Calendar Days or a custom range spanning your whole open campaign.
  4. Save it and note the Query ID
  5. Go to Settings → Account Settings → Flex Web Service → enable it and copy the Token
  6. Paste both below and click Import

⚠️ If you see a warning about missing entry data, your query's date range only covers the exit day — widen it so the BUY fills are included.

Token & Query ID are saved locally so you only have to enter them once.

What gets imported?

  • Ticker, asset class, direction, entry date/time, price, size, commission
  • Tagged automatically with ibkr + a unique exec ID to prevent duplicates on re-runs
  • Trades are imported as open — you edit them later to add stops, exit info, thesis, screenshots, etc.
